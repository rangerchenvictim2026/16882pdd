# 版本记录

## 0.1.0 · 2026年11月4日

首个可展示的实验性MVP，项目名称为16882pdd，采用MIT许可。

- 集中展示1688货源筛选、拼多多关键词竞品、单品销量及保守货价差候选。
- 支持个人选品记录、标签、备注、状态、最多4件对比及中文CSV。
- 提供小批量串联、限速、暂停、取消、断点和过程复盘。
- 拼多多默认沿用Safari会话进行窗口采集，保留Chrome备用代码及其未通过的真实无头限制。
- 增加独立端口及临时数据库的虚构演示模式、本地原创插图和演示截图。
- 整理公开文档、依赖说明、许可证、忽略范围及源码打包脚本。

原生平台条件不能代替逐件严格15天上新和近30天销量证据；关键词结果不证明同款。价差不等于利润，新版整批真实采集的持续稳定性仍待进一步验证。
