# 已知限制与验证范围

## 当前可展示的能力

v0.1提供1688条件筛选、关键词竞品、单品销量与价格整理、正货价差候选、人工选品管理及任务记录。独立演示模式可在不连接平台的情况下体验该链路。

真实Safari关键词搜索和小批量竞品读取已有成功记录。新版20条货源→前5件各5竞品的整批持续可用性仍需更多真实测试，不能用离线演示或自动化测试代替。

## 登录和浏览器

- 拼多多默认使用Safari窗口采集，需要macOS和用户手动授予相关权限。
- 自动操作不主动激活Safari，但窗口仍然存在，不是真正无头。
- Chrome可见与无头曾同时显示系统繁忙，Safari同日可搜索；原因尚未确定，不能据此断言是网络、登录失效或无头检测。
- 浏览器保留会话不能保证登录永不过期；验证码、登录和访问限制仍可能出现。
- 不自动订购接口、代理或插件，不提供绕过验证码或访问限制的能力。

## 商品字段和排序

- 1688原生新品条件不等于逐件核实15天上新；原生销量排序参数不等于近30天销量。
- 实际报价需复核整个规格区间；仍应人工核对起订量、包装数和收货地区报价。
- 拼多多只比较本次取得的可用候选，不能声称全平台销量排行榜。
- 店铺总销量、买家数、成交金额和未知单位不能冒充单品销量。
- 关键词只能寻找候选，无法证明同款同规格；图搜尚未接入。

## 价差与利润

当前仅计算竞品最低展示价减货源最高展示价。没有扣除运费、平台费用、推广、退换货或税费，不提供净利润结论，也不根据单次当前销量推断销量增长。

## 演示与部署

演示资料全部虚构，时间表示示例生成时间，商品链接不提供真实购买入口。CSV仍可能包含用于验证字段结构的虚构ID和平台格式链接，不能当作采购依据。

当前仅监听本机，不建设多用户身份系统，也不作为可直接公开到互联网的托管服务。启动脚本和真实Safari接入面向macOS，其他操作系统未验收。

平台页面结构和访问策略可能改变。字段读取失败会明确记录并停止，不保证后续一直可采集。

## 暂未实现

按图竞品搜索、店铺经营看板、商品上下架、采购、跨境业务、费用参数和估算利润均留待后续版本。
