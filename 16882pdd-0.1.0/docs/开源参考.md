# 开源项目与官方资料参考

核实日期：2026年11月2日。仅阅读公开说明和可取得的源码，没有安装插件、运行外部项目、订购代理或付费接口，也没有直接复制这些项目的实现。

## 拼多多采集示例

[wfgsss/pinduoduo-scraper-example](https://github.com/wfgsss/pinduoduo-scraper-example)提供MIT许可的Playwright、Crawlee采集示例，可参考关键词检索、滚动加载、详情队列和异常截图的组织。

其源码模拟iPhone Safari的浏览器标识，并非原生Safari控制方案；包含Apify代理相关逻辑，不能据此认定为长期免费的官方数据接口。销量单位、店铺销量排除和当前网页选择器仍需独立核验。

## 多平台比价工具

[halo0017/PriceCompare](https://github.com/halo0017/PriceCompare)的公开说明包含独立平台采集器、SQLite、价格历史、桌面交互和每日调度，可参考模块职责与本地存储组织。

尚未验证当前拼多多接入是否可用；未核实标准开源许可，当前仅参考设计，不复制代码。

## 历史拼多多采集项目

[Northxw/Pinduoduo](https://github.com/Northxw/Pinduoduo)是2019年的Scrapy项目，可参考商品字段与导出、分析组织。其旧接口与动态参数不作为当前接入依赖；公开说明限制商业使用，未按可直接商用的开源组件采用。

## 官方资料

- [Apple开发者设置](https://developer.apple.com/documentation/safari-developer-tools/developer-settings)：Safari网页脚本控制权限的说明。
- [Safari WebDriver说明](https://developer.apple.com/documentation/safari-developer-tools/webdriver)：自动化窗口与普通登录会话隔离，不能假定共享用户已登录状态。
- [Playwright持久化浏览器](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)：固定资料目录可保存浏览器会话；不能让多个浏览器同时使用同一资料目录，也不应自动控制日常Chrome主资料。
- [Playwright浏览器与无头说明](https://playwright.dev/python/docs/browsers)：Chrome无头模式的支持和差异，接入时应按已安装版本核对。
- [拼多多隐私政策](https://www.yangkeduo.com/pdd_privacy_policy.pdf)：2.4节说明设备、日志等信息可能用于账户风险判断和身份验证。该说明不能证明本次跳转登录页的具体原因，也没有提供本项目可依赖的安全访问频率阈值。
