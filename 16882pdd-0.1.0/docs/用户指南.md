# 用户指南

## 演示体验

按照README安装依赖后，运行`python scripts/start.py --demo`，打开本机8766端口。页面顶部会持续显示“演示模式 · 全部为虚构示例”。

首次打开已有20件示例货源、前5件各5条示例竞品及1条选品记录。虚构竞品中包含正价差和非正价差，便于查看筛选效果。演示也用单品口径排除店铺总销量。

1. 查看比价候选，调整“最低货价差”，观察结果变化。
2. 改价格上限并点击“开始筛选与比价”，体验筛选和自动比价。
3. 展开“1688原始结果与采集记录”，选择商品并保存到选品库。
4. 在选品库编辑状态、标签和备注，或选择最多4件对比。
5. 导出筛选结果或完整竞品，核对中文表头、价格、销量和时间。

演示不需要登录，不打开平台浏览器，商品链接不可跳转。CSV中的ID及平台格式链接也是示例占位。服务重新启动会生成新的临时资料；保留修改请先导出。正式模式的记录和登录资料不会进入演示。

## 真实采集准备

真实采集当前面向macOS：安装Google Chrome并保留Safari。运行`python scripts/start.py`后打开8765端口。

- 1688：点击“打开登录浏览器”，在专用Chrome窗口中手动登录。登录资料与日常Chrome资料隔离。
- 拼多多：点击“查看 Safari / 登录”，在独立采集窗口中手动登录。需要时在系统设置中允许启动程序控制Safari，并在Safari开发者设置中允许来自Apple事件的JavaScript；由用户自行选择是否授予。
- 填好关键词后，点击“验证 Safari连接”，确认当前关键词列表可读取。验证只代表当时可访问，不能保证以后免登录或免校验。

不要把密码或验证码填进工作台的备注或关键词输入框。分平台的完整登录步骤、Safari权限说明和本机资料范围见[登录与隐私](登录与隐私.md)。

## 从货源到竞品

输入关键词、运费条件、价格范围和收货省市。默认使用平台新品及一件代发筛选，并逐件核对实际价格。最高15元时，36元商品或12～35元的价格区间均应排除。

开启“自动对前5条货源比价”后，一次最多读取20个候选，再取合格结果前5件查询竞品。拼多多先在本次候选内比较可核实的单品销量，每件保留最多5条；不能保证平台全局前5名，也不会拿店铺总销量代替单品销量。

只展示正货价差候选，门槛可以手动提高。没有通过的原因、完整竞品和时间日志在“采集设置与过程复盘”中。重新比价前可调整每件货源的关键词。

## 如何理解结果

货源成本参考使用1688最高展示价，竞品售价参考使用拼多多最低展示价，两者相减得到保守货价差。报价条件、包装数量、规格和是否同款仍需核对；价差没有扣除业务费用。

商品和竞品保留各自数据时间，刷新前的记录不能称作实时价格。拼多多销量按网页显示口径记录，不自动解释为近30天销量或销量增长。

## 暂停、停止和继续

真实采集的页面操作至少间隔6秒，关键词开始至少间隔20秒；这些是本机减少重复访问的策略，不是平台公布的安全阈值。

遇到登录或验证时暂停，完成结果和当前候选断点保留。用户处理后手动继续。系统繁忙或限制访问时停止，并至少冷却5分钟，不自动刷新或切换浏览器；冷却结束也不代表平台一定恢复。

取消会保留已完成结果。服务重启不会自动续跑；超过24小时的候选断点要求新建搜索，避免混用过期报价。

## 保存和备份

选品记录按平台商品ID去重，刷新资料保留个人备注及状态。中文CSV可用于人工复盘；导出内容会处理可能被表格软件当作公式的文本。

正式业务数据保存在`data/`，可从设置中备份。备份默认不包含浏览器登录资料。恢复会替换业务数据，并先保存恢复前备份；请先确认所选文件。

演示备份只包含该次临时演示资料，不要导入到正式工作台。
