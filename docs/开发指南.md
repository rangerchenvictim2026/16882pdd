# 开发、验证与源码打包

## 环境

当前验证环境为macOS、Python 3.13及Node.js 24。Vite构建需Node.js 22.12或更新版本，前端依赖使用pnpm锁文件安装。真实浏览器接入还需本机Chrome及Safari，演示模式不需要平台浏览器。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
pnpm install --frozen-lockfile
pnpm run build
```

`requirements.txt`保存依赖范围，`requirements.lock.txt`保存本项目验证过的Python版本组合。日常运行无需反复安装。

## 启动

```sh
# 演示，8766端口和全新临时数据库
python scripts/start.py --demo

# 正式本机工作台，8765端口
python scripts/start.py
```

可增加`--no-open`避免自动打开系统默认浏览器。演示模式不使用`WORKBENCH_DATA_DIR`。

调试后端时也可使用以下方式；仅绑定本机地址：

```sh
WORKBENCH_DEMO=1 .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8766
```

前端开发使用`pnpm dev`，Vite代理配置见`vite.config.ts`。完整联调可直接构建后查看本机服务。`tests/ui_server.py`是开发用隔离结构样本，不是公开演示入口。

## 检查

```sh
.venv/bin/python -m pytest -q
pnpm run build
```

测试不连接真实平台。覆盖筛选口径、整段规格价格、单品销量、任务暂停取消、断点、价差、保存与导出，并增加演示隔离和源码包排除范围检查。已有一条Starlette/httpx测试客户端弃用提示，尚未迁移替代依赖。

自动化检查通过不等于真实平台始终可用。登录持续性、字段覆盖和整批采集需要另做真实验收。

## 源码包

```sh
.venv/bin/python scripts/package_demo.py
```

生成`release/16882pdd-v0.1.0-source.zip`和SHA-256摘要，包内含逐文件校验清单。

脚本只收集明确的根目录文件、源码目录、公开说明和演示截图。遇到符号链接或缺少许可证会停止。不包含`data/`、真实数据库、Chrome资料、内部进度、原始截图、依赖环境或构建产物；使用者需自行安装依赖并构建。

`.gitignore`也排除了本机资料，但它不能删除已提交的历史内容。发布前应检查实际待提交文件，尤其是新加源码、配置和截图。项目许可证不改变第三方依赖和平台资料的授权。
